# Apollonian Gasket Fractal Visualization

This project generates an interactive visualization of the Apollonian gasket fractal using Python and matplotlib. The Apollonian gasket is a fractal generated by repeatedly filling the interstices between mutually tangent circles with new tangent circles.

It's a program that was rewritten in Python using the video made by The Coding Train at [Challenge #182 - Apollonian Gasket](https://thecodingtrain.com/challenges/182-apollonian-gasket).
AI was used to help with translating certain JavaScript functions and to add comments throughout the code.

## Overview

The Apollonian gasket is a fascinating fractal that arises from a simple geometric construction. Starting with three mutually tangent circles, the process of adding smaller tangent circles continues infinitely, creating a intricate pattern. This project provides an interactive visualization where users can click to generate new tangent circles and observe the fractal’s development.

## Installation

To run this project, you’ll need to have Python and the required libraries installed. It’s recommended to use a virtual environment.

1. **Clone the repository:**
    
    ```bash
    git clone https://github.com/your-repo/apollonian-gasket.git
    cd apollonian-gasket
    ```
    
2. **Set up a virtual environment (optional but recommended):**
    
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```
    
3. **Install the dependencies:**
    
    ```bash
    pip install matplotlib
    ```
    

## Usage

Run the project using the following command:

```bash
	python main.py
```

A window will open displaying three initial circles. Click anywhere within the window to generate new tangent circles, allowing you to interactively explore the fractal’s growth.

## Structure

The project consists of several Python files, each serving a specific purpose:

- **`main.py`**: The main script that initializes the fractal and handles user interactions.
- **`geometry.py`**: Contains functions for computing tangent circles using the Descartes circle theorem.
- **`complex_number.py`**: Provides a `Complex_number` class for handling complex arithmetic.
- **`circle.py`**: Defines the `Circle` class and utility functions for validating and drawing circles.

## Dependencies

- **Python 3.x**: The project is compatible with Python 3.x.
- **matplotlib**: Used for plotting and creating the interactive visualization.
